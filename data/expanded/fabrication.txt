# Outfits and ships that can only be built in the player's fabrication bays,
# and the blueprints for building them.
#
# blueprint "<name>"
# 	outfit "<outfit>" | ship "<ship model>"
# 	cost <credits>
# 	material "<commodity>" <tons>          (any number; taken from the station's
# 	                                         facilities and warehouse)
# 	days <days to build>
# 	requires "<condition>"                 (only once the player has this condition)
#
# Fabricated items are resold at a fully depreciated value, like gifts, so the
# credit cost of each blueprint is kept above a quarter of the item's value.
#
# Art: every image is in an "expanded" folder under images/. To use new art,
# overwrite the file with the same name and size. See docs/expanded/art/README.md.
